🗂️ API de Clientes
API RESTful desenvolvida em JavaScript para gerenciamento de clientes, seguindo boas práticas de arquitetura de backend.
Sobre o Projeto
Serviço de backend para operações de CRUD (criação, leitura, atualização e exclusão) de registros de clientes. Desenvolvido para consolidar conhecimentos em construção de APIs RESTful com JavaScript.
Stack

JavaScript — linguagem principal
Node.js — ambiente de execução
Arquitetura RESTful com separação de responsabilidades
